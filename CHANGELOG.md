# Changelog

## 1.0.0

Initial release of Spark and Sift.

- Bowl sifting with configurable rewards from multiple materials.
- Fire Drill and Flint Fire Starter for primitive firemaking.
- Bowl archaeology and campfire cooking rewards.
- Advancements for sifting, archaeology, firemaking, and campfire cooking.
- Optional Mod Menu configuration and animation compatibility with Punchy and Smooth Player Animations.
- Multiplayer configuration synchronization.
